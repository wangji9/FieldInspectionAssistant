# 知识图谱抽取与审核

在“智能助手 → 知识图谱”中，选择“导入资料”或选择已有对话后点击“抽取对话”；也可通过“输入文本”在单独窗口输入。资料名称由文件或会话自动记录。右上角图谱设置中可控制是否允许扩展本体。

短资料每段只调用一次本地文字模型，长资料按原文顺序分段。每段最多生成 12 条候选；达到上限时界面会提示可能遗漏，资料较密集时应分段检查。模型生成候选后，系统逐条检查类型、原文证据和两端实体；不合格的候选被排除。个别关系缺少证据时，仅在原文存在唯一一条同时包含两端实体的短句时使用该原文，不拼接或编造证据。模型偶尔漏掉 JSON 结束括号时仅恢复结构，不补写字符串或事实。候选是待审核内容，不能保证抽取完整或语义正确，保留前应检查原文。

中间图谱动态显示候选关系。可拖动节点、拖动画布、滚轮缩放，或使用“适应”“−”“+”及“动态布局”。点击“筛选候选”可逐条查看原文并勾选；未选关系在预览图中淡化。“保留所选”才创建来源和版本，并仅扩展所选关系需要的类型；“放弃”不更改数据库。遇到后续分段出错或停止时，已完成的有效候选仍可审核。

候选仅驻留当前登录会话内存，退出或切换账号即清除。确认时检查基准版本是否已变化，数据与来源、证据、版本在一个数据库事务中提交。版本变更摘要记录候选数量、保留数量、模型调用次数和耗时。
