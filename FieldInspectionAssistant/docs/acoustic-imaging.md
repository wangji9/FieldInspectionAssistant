# 六麦声学成像

打开「工程与采集 → 声音与信号 → 声学成像」，选择摄像头并开始成像。应用从 ListenGo 数据口读取同步六路 PCM，复用正在进行的同源采集。停止本页启动的采集时，六路原始 WAV 进入录音管理。

## 计算与显示

- 频域模式在目标频率对应的 FFT 频点做延时求和，频谱红线和成像使用同一个频率设置。时域模式在每个方向计算延时补偿后的通道对积分能量，禁用目标频率输入和频谱图。
- 宽带 SRP-PHAT 使用设置中的频带和麦克风对相位响应，适合具有较宽频谱的声音。单频 MVDR 使用目标频点的滚动协方差和对角加载，对该频率做自适应空间滤波。
- 动态范围以峰值为上限，显示峰值以下指定 dB 范围的空间功率。缩小范围会收紧可见热区，信号实际电平越高，热区越明显。有效采样到达时持续生成热图，静音和完全重复的通道显示均匀底色。
- V4L2 采集和 JPEG 解码并行，待解码队列只保留最新帧。曲线和热图按约 30 Hz 读取最新采样，同一时刻只计算一个音频窗口。视频和热图使用独立纹理及同一裁切映射，叠加跟随旋转和镜像。波形显示最近 1024 个样点，多通道总览显示红色平均线。
- 方向稳定且有足够语音后，对同一原始采样做延时求和，再用 CAM++ 和本地档案匹配。匹配结果限定在相近的方向和时间。低置信或没有注册的声音保留为未知。

## 阵列与摄像头标定

应用预置参考的六点等间距圆环，默认半径为 35 mm。板端 USB 设备名不能提供实测阵列半径、环上通道映射或相机外参。实际半径按麦克风进音孔中心测量。

在「阵列和声学参数」启用「固定环形机位」后，成像引擎按镜头光轴上的参考距离建立扫描平面。每个画面网格点通过相机相对麦阵的旋转和平移换到麦阵坐标系。四种成像算法和声纹波束提取都使用从该点到六个麦克风的球面传播距离。

「采用照片初值」将镜头上下偏移设为约负 0.13 倍阵列半径，左右和前后偏移先取零，参考工作距离取 1 m。此操作沿用已有半径、通道顺序和镜头角度，并清除已标定状态。偏移以麦阵中心为原点，朝拍摄方向看右、上、前为正。实际通道顺序、半径、前后偏移和参考距离应按现场实测填写。

用同一测试音复核画面中央、左右和上下，调整偏航、俯仰、滚转和视场。未标定时，状态栏显示阵列坐标下的方位。相机或阵列单独移动、更换镜头后需要重新标定。

平面阵列在前方假设下估计方向。距离、背面声源与强反射需要结合现场判断。近距离或镜头与阵列相距较远时，两个观察点的视差会影响画面投影。

## 验证

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DFIELDOPS_VOICE_TESTS=ON
cmake --build build -j 3
ctest --test-dir build --output-on-failure
```

声学回归测试覆盖正负方向、镜头偏航补偿、静音门限、重复通道、混合频率的独立定位以及目标频率缺失。用板端实景复核左右位置后才能记录机位的标定状态。

算法与几何资料见 [DiBiase 的声源定位研究](https://glat.info/ma/av16.3/2000-DiBiaseThesis.pdf) 和 [讯飞六麦参考设计](https://www.xfyun.cn/doc/solutions/hardwareUniversal/CAEdesign.html)。
