# 联网搜索

文字问答、图片问答和智能体分析的输入框右侧有“联网”按钮。高亮表示启用，灰色表示关闭；默认关闭，各账号、各页面独立保存。也可在助手设置或智能体工具设置中切换。

开启后发送消息，会搜索本次输入的问题，获取最多五条公开搜索结果摘要，再交给板端常驻模型回答。图片和录音文件不会提交搜索引擎，图片识别、语音转写及模型推理仍在板端运行；智能体的语音附件先转写，本次转写内容会作为任务的一部分参与搜索。

图片问答开启联网时，先由视觉模型读取图片，再由文字模型结合图片观察和搜索资料生成一条带引用的最终回答；中间观察不会作为另一条回答显示。

智能体启用后会在执行计划中加入 `web_search`，可与数据库、知识图谱、图片分析等工具一起使用。关闭后不会注册为本次任务的可用工具。模型规划不能绕过所选工具清单。

搜索结果是第三方网页的搜索摘要，未读取网页全文。回答中的 `[WEB1]` 等编号只允许引用本轮真实结果，末尾列出可点击的来源。搜索引擎可能提供跳转链接，点击后进入原始页面。网页摘要不能代替现场测量、正式标准或人工复核。

当前使用 360 公开搜索，未取得有效结果时尝试搜狗搜索。使用系统 HTTPS 校验证书，无需 API 密钥。网络请求异步执行，总等待最长十八秒，限制响应大小和结果数。被搜索引擎验证拦截、无结果或断网时，本轮直接提示搜索失败，可重试或关闭联网后重新提问；可在搜索过程中停止。

查询、时间、来源标题、网址和摘要会随智能体工具观测保存；普通问答将来源链接保存在原有完整会话及导出内容中，运行指标包含本轮搜索证据。设置保存在现有 `product_settings` 的 `web_search/<用户ID>/<页面>`，文件镜像位于本账号 `assistant/users/<用户ID>/preferences.json` 的 `web_search` 字段。无需变更数据库结构。
