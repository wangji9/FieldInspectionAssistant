# 现场巡检助手变更记录

## 多模态巡检与报告归档

- 工程证据保存 UTC 毫秒时间和时间来源。融合事件按设备、测点、巡检记录及基准证据前后 60 秒筛选，保留对齐条目和相对偏移。
- 诊断在后台读取图像与视频，在 RK1828 上分析代表性图像及一段视频的三帧。PCM16 WAV 计算幅值，时序 CSV 计算采样统计，80×60 温度矩阵计算最低、最高和平均温度。文字、读数、工况、阈值及采集指标共同进入诊断上下文。
- 板端语义模型暂不可用时，保留已解码的像素或采样指标和处理状态。图像亮度、视频帧差与数字音频幅值的单位各自独立。诊断建议保留人工复核入口。
- 多模态图谱从工程 SQLite 重建。工程、设备、测点、对齐证据、事件、模型诊断、巡检记录、缺陷与归档报告可以互相追溯。工程另存和归档带上原始证据、诊断观测及报告快照。巡检记录和缺陷详情仍使用其所属业务数据库。
- 缺陷进度按已完成环节计算。复核退回时恢复到整改环节，保留退回记录。实际关闭后显示 100%。
- 新归档的事件报告冻结证据与判定依据，提供多模态证据报告、巡检事件摘要、缺陷整改跟踪报告三种 PDF。历史报告继续可读，正式巡检报告的签审流程沿用原有版本机制。
- 增加泵组公开素材演示。视频与录音来自不同设备，温度矩阵及巡检业务读数为培训样例。素材出处与演示复现命令见 [工程运行说明](../README.md#多模态泵组演示)。

### 板端验收范围

工程新建、保存、重新打开、另存与归档导入。测点和判定基准登记、异常事件关联巡检与缺陷、整改退回及再次关闭。检查六种模态的对齐、RK1828 诊断、图谱关系，以及三种 PDF 的生成和页面版式。
