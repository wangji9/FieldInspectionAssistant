# 六麦声学成像

打开「工程与采集 → 声音与信号 → 声学成像」，选择摄像头并开始成像。应用从 ListenGo 数据口读取同步六路 PCM，复用正在进行的同源采集。停止本页启动的采集时，六路原始 WAV 进入录音管理。

## 计算与显示

- C++ 对六路同时采样进行频带选择和加窗，计算 15 个麦克风对的 GCC-PHAT。在镜头视场网格上累加插值后的时延响应，使用 SRP-PHAT 估计主声源方向。
- 热图以归一化空间响应表示峰值和周边分布。六路电平以 dBFS 表示。小于门限、六路数据复制或空间响应不集中时，清除定位标记。
- 摄像头和六麦采样使用同一板端时间。界面显示采集时间和音画时差，时间差过大时不叠加热图。音频时间基于主机收到采样的时刻，设备间同步精度取决于实际链路。
- 方向稳定且有足够语音后，对同一原始采样做延时求和，再用 CAM++ 和本地档案匹配。匹配结果限定在相近的方向和时间。低置信或没有注册的声音保留为未知。

## 阵列与摄像头标定

应用预置参考的六点等间距圆环，默认半径为 35 mm。板端 USB 设备名不能提供实测阵列半径、环上通道映射或相机外参。实际半径按麦克风进音孔中心测量。

在「阵列和声学参数」填入半径、通道排列、顺逆时针、起点角和相机视场。先将相机与阵列固定，再在画面中央和左右放置同一测试声源，核对方位符号并调整偏航、俯仰和滚转。更改相机镜像、旋转、镜头或阵列安装后复核机位。保存参数后会按新几何重新计算。

平面阵列在前方假设下估计方向。距离、背面声源与强反射需要结合现场判断。近距离或镜头与阵列相距较远时，两个观察点的视差会影响画面投影。

## 验证

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DFIELDOPS_VOICE_TESTS=ON
cmake --build build -j 3
ctest --test-dir build --output-on-failure
```

声学回归测试验证正负方向、镜头偏航补偿、静音门限和重复通道保护。用板端实景复核左右位置后才能记录机位的标定状态。

算法与几何资料见 [DiBiase 的声源定位研究](https://glat.info/ma/av16.3/2000-DiBiaseThesis.pdf) 和 [讯飞六麦参考设计](https://www.xfyun.cn/doc/solutions/hardwareUniversal/CAEdesign.html)。
